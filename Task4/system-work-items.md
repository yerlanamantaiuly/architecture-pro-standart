## Крупные задачи по системам

### Сервис депозитных заявок и ставок
- Выделить и формализовать доменную модель ставок, версий ставок и событий публикации.
- Реализовать API выдачи актуальных ставок для внутреннего кол-центра.
- Реализовать планировщик экспорта ставок для внешних каналов.
- Реализовать генерацию файла ставок в согласованном формате.
- Добавить аудит публикации, выгрузки и ошибок доставки.

### Система кол-центра банка
- Добавить интеграцию с API ставок нового депозитного контура.
- Добавить экран или виджет отображения актуальных ставок оператору.
- Реализовать отображение версии и времени актуальности ставок.
- Настроить права доступа для операторов кол-центра.

### Контур файлового обмена / SFTP
- Развернуть и настроить файловый контур передачи ставок партнеру.
- Настроить ключи, доступы, каталог размещения и политику хранения файлов.
- Реализовать прием, подтверждение и мониторинг доставки файла.
- Настроить алерты на отсутствие новой версии или неуспешную выгрузку.

### Система партнерского кол-центра
- Согласовать формат файла и состав полей.
- Реализовать загрузку файла ставок в процесс работы партнерского кол-центра.
- Настроить регламент обновления файла и обработку устаревшей версии.

### Бэк-офис / операционный процесс ставок
- Перевести публикацию ставок из Excel-процесса в системный контур ставок.
- Определить регламент утверждения, публикации и отзыва версии ставок.
- Настроить роли и разграничение доступа между депозитным и кредитным блоком.

### Инфраструктура и эксплуатация
- Настроить мониторинг API ставок, планировщика выгрузки и SFTP-канала.
- Подготовить runbook для повторной доставки и разборов инцидентов.
- Провести нагрузочную и интеграционную проверку с внутренним и партнерским кол-центрами.
